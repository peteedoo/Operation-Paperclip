# Operation-Paperclip

A tiny, deterministic CEO simulation: allocate cash, grow the team, fund
research, and maximize paperclip production.

## Run it

```bash
python paperclip.py --days 5
```

The CEO hires once, funds research once, and produces paperclips with the
remaining budget each day. Run the focused test suite with:

```bash
python -m unittest -v
```
